# Spanish content and grading

Verified October 1, 2026 against the supplied Unit 2 vocabulary DOCX (two pages),
subject pronoun/SER chart (two scanned pages), and DOCTOR SER chart (one scanned page).
Originals remain private and are not part of this repository or production output.

- Use the fuller DOCX convention: ellos includes masculine or mixed groups. The PDF
  simplifies that label to boys. Vosotros/vosotras → sois is shown, mainly used in Spain.
- la mesa = table; el escritorio = desk; quince mochilas = fifteen backpacks.
- la goma means glue in this class list; dialects also use it for eraser. Scene context
  makes the intended meaning clear. Both pluma and bolígrafo are valid pen synonyms.
- DOCTOR description/characteristics overlap; no scored question arbitrarily chooses
  between those two labels. Identification, events, material and possession are included.
- A pen can be useful when studying. “Para estudiar necesito un bolígrafo” has no universal
  false answer here and is excluded from scored questions.
- No original backpack picture or official exercise answer key was supplied. Generated
  hay questions and their models use the same inventory displayed to the learner.
- Accent omission in a meaning-focused sentence receives a modeled spelling correction.
  Explicit el/él and tu/tú contrast items require the correct accent. Answer validation
  checks complete accepted responses; finding a correct keyword is insufficient.
- English help translates or contextualizes the question. Answer explanations appear
  after submission. Hints and corrected answers never count as independent first success.
- The big quiz has 60 questions. Practice letter bands: A ≥90%, B ≥80%, C ≥70%, D ≥60%;
  lower scores receive “More practice.” The denominator is the completed session size;
  the numerator is correct, unhinted first responses. No school grade or proficiency
  certification is implied. Only aggregate results are stored in browser storage.

Model Interpretation & Prediction

Question 1 5 pts · True / False
Based on the estimated demand model, we can interpret the intercept as: "The predicted demand is 548.37 when the fare is zero, the hour is not a peak hour, the day is not a weekend day, the weather is not rainy, and there is no special event."

TRUE. The intercept represents the predicted value of the dependent variable when all independent variables equal zero. Since all the contextual variables (PeakHour, Weekend, Weather, SpecialEvent) are binary indicators, setting them to zero corresponds exactly to the baseline condition described in the statement. Setting Fare = 0 gives the intercept value of 548.37.

✓ Answer: TRUE
Question 2 5 pts · True / False
Based on the estimated demand model, we can interpret the estimated fare slope as: "The predicted demand decreases by 150.55 when the fare increases by 1 unit (in this case $1)."

FALSE. Because the model includes interaction terms between Fare and the contextual variables, the marginal effect of Fare on demand is not a single fixed number. It depends on the values of PeakHour, Weekend, Weather, and SpecialEvent. The coefficient −150.55 is the effect of Fare only when all interaction partners are zero (non-peak, weekday, clear weather, no special event). In any other condition, the effective fare slope changes.

✓ Answer: FALSE
Question 3 5 pts
Holding all IVs constant, changing the hour from a regular to a peak hour increases the demand by:

Explanation

Because PeakHour appears both as a main effect and in an interaction with Fare, changing PeakHour from 0 to 1 changes predicted demand by:

ΔDemand = β₂ + β₆ · Fare = 206.95 + 17.87 · Fare

The effect of switching to a peak hour depends on the current fare level. It is not a single constant — it is 206.95 + Fare × 17.87.

✓ Answer: 206.95 + Fare × 17.87
Question 4 5 pts · True / False
By looking at the estimate of the interaction term for Fare × Weekend, we can say the following: "Holding all IVs constant, consumers are less price sensitive during the weekends than weekdays."

TRUE. The Fare×Weekend interaction coefficient is positive (+21.87). The main effect of Fare is −150.55 (negative, as expected — higher fares reduce demand). On weekdays (Weekend = 0), the fare slope is −150.55. On weekends (Weekend = 1), the fare slope becomes −150.55 + 21.87 = −128.68. Since −128.68 is less negative than −150.55, demand is less responsive to fare increases on weekends — i.e., consumers are less price sensitive on weekends.

✓ Answer: TRUE

Conjoint Fractional Factorial Design

  • Define attributes and their levels, then generate an efficient fractional factorial design
  • See full factorial profile count vs the reduced (fractional) number of profiles
  • Export the design profiles and a dummy-coded design matrix as CSV files
  • Powered by R (AlgDesign::optFederov) running entirely in your browser via WebR

1. Define Attributes

Add at least 2 attributes, each with 2 or more levels. Enter the levels for each attribute as a comma-separated list. The first level of each attribute is treated as the reference (baseline) level in dummy coding.

2. Design Statistics

The full factorial count is the product of the number of levels across all attributes. The fractional design selects an efficient subset.

1. Choose Data Format

Pick how your data is laid out before uploading. The required columns and the data preview both depend on this choice.

Long Format recommended

Each row represents one alternative within one choice occasion. If there are 3 alternatives per choice, each occasion has 3 rows. Required columns: a Choice ID, an Alternative name, a binary Choice indicator, and any alternative-specific attributes (e.g., Price).

Wide Format

Each row represents one choice occasion. There is a Choice ID column, one binary choice column per alternative (including the outside option), plus alternative-specific attribute columns named with a per-alternative suffix (e.g., Price_Coke, Price_Pepsi).

5. Specify the Model

Independent variables are split into two groups based on whether they vary by alternative within a choice occasion. Choice-Specific IVs (e.g., Price) take a different value across alternatives within an occasion — they can use either a single slope across alternatives or a per-alternative slope. Choice-Invariant IVs (e.g., Summer, Income) are constant across alternatives within an occasion — they must use a per-alternative slope, because a single slope would cancel out of the choice probabilities.

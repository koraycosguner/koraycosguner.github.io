Data Requirements

This tool requires two CSV files (and one optional):

  1. Design Matrix (Dummy Coded): a CSV where the first column is Profile and all remaining columns are dummy-coded attribute levels. Column names follow the format AttributeName_LevelName (e.g., Price_60, DVR_HD_DVR). The base level for each attribute is omitted (all zeros). You can generate this file using the Conjoint Fractional Factorial Design Tool.
  2. Ratings Data: a CSV where the first column is Profile (matching the design matrix) and each additional column is a respondent's ratings (e.g., Respondent_1, Respondent_2, ...). Ratings should be numeric (e.g., 0 to 100).
  3. Profiles CSV (Optional): the original (non-dummy-coded) profiles from the Design Tool. If provided, base level names are automatically detected and labeled (e.g., "50" instead of "Base" for Number of Channels).

Step 2: Part-Worth Utilities (OLS Regression)

Individual-level OLS regression coefficients. Base levels = 0 (reference category). The R-squared row shows how well each respondent's ratings fit the model: values near 1 mean a tight fit, while a low value can flag a careless or inconsistent rater.

Step 5: Individual Choice and Choice Probability Simulator

Define product options manually or upload a dummy-coded profiles CSV (same format as the design matrix). Each row becomes a product option.

How these numbers are computed. For each respondent we predict each option's utility from that respondent's part-worths (intercept + selected level utilities). Choice is the option with the highest utility (first-choice rule). Choice probability uses the share-of-utility (BTL) rule: probability = option utility divided by the sum of utilities across options, after clamping any negative utility to 0 so shares stay between 0% and 100% and add to 100%. This rule is scale dependent (it depends on the rating scale and the intercept).
Step 6: Market Share

Aggregated market shares from individual choices and choice probabilities. First Choice Share is the percentage of respondents whose top-utility option is that product (winner-take-all, more volatile with few respondents). Choice Probability Share averages each respondent's share-of-utility probabilities (smoother, rewards options that are a close second). Both columns sum to 100%.

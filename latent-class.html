Latent Class Regression

  • Estimate segment-level (finite mixture) regressions with the flexmix R package, with no R install required
  • Linear, Poisson, or Binary Logistic regression, with 1 to 10 segments
  • Group repeated rows by a Consumer / Household ID so each ID belongs to one segment
  • View segment sizes, per-segment coefficients, AIC / BIC, and segment-specific equations
  • Compare several numbers of segments by BIC, download ID-to-segment assignments and an R script

2. Specify the Model

A latent class regression splits the sample into k unobserved segments and estimates a separate regression for each one. Pick the regression type that fits your dependent variable.

With an ID, all rows of the same consumer or household are assigned to the same segment (the | ID term in flexmix).
